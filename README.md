# OMM Project 2026

Projekat iz predmeta OMM na Matematičkom fakultetu Univerziteta u Beogradu.

## Opis projekta

Ovaj projekat modeluje širenje epidemije korišćenjem SIR epidemiološkog modela i analizira uticaj različitih mera zaštite, uključujući:

- osnovni SIR model
- vakcinaciju
- karantin
- poređenje scenarija
- vizualizaciju rezultata

Simulacije i grafici su implementirani u MATLAB okruženju.

## Struktura projekta

- `grip.m` — glavna MATLAB skripta za simulaciju
- `grip.tex` — LaTeX izveštaj projekta
- `grip.pdf` — generisan PDF izveštaja
- `fig_basic.eps` — grafik osnovnog SIR modela
- `fig_scenariji.eps` — grafik poređenja scenarija
